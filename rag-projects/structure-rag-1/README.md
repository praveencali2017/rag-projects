# structure-rag-1

A text-to-SQL RAG agent that answers natural-language questions over the [Chinook](https://github.com/lerocha/chinook-database) sample SQLite database (a digital media store: artists, albums, tracks, customers, invoices, etc.) using LangChain and OpenAI.

Ask a question like *"List all the customers from Brazil"* and get back a natural-language answer, generated by translating your question into SQL, running it against the database, and summarizing the results.

## How it works

The pipeline in [`sql_agent.ipynb`](sql_agent.ipynb) is a sequential LangChain chain (no agentic tool-calling loop):

1. **Schema introspection** — the full database schema (tables, columns, 3 sample rows each) is loaded once via `SQLDatabase.get_table_info()` and embedded into the prompt.
2. **SQL generation** — an LLM prompt (`sql_query_generation_prompt`) takes the user's question plus the schema and generates a single SQLite query.
3. **Cleaning** — `clean_sql_query()` strips any markdown code fences from the model's output.
4. **Validation** — `validate_sql_query()` rejects any query containing `DELETE`, `DROP`, `TRUNCATE`, `INSERT`, `UPDATE`, `CREATE`, or `ALTER`, enforcing a read-only guardrail.
5. **Execution** — `retrieve_data_from_database()` runs the validated query against `data/chinook.db` via `sqlite3` + `pandas`, returning a DataFrame.
6. **Response generation** — a second prompt (`final_response_system_promt`) turns the result rows into a friendly natural-language answer.

```
user question ──▶ generate SQL ──▶ clean ──▶ validate (block DDL/DML) ──▶ run against chinook.db ──▶ summarize results ──▶ answer
```

> **Safety note:** the keyword blacklist is a basic guardrail for a demo/notebook context, not a hardened SQL-injection defense. Don't point this at untrusted user input in production without stronger protections (e.g. a read-only DB connection, parameterized queries, or an allow-listed query layer).

## Tech stack

- [LangChain](https://python.langchain.com/) core (`init_chat_model`, `PromptTemplate`)
- `langchain-openai` — OpenAI chat models
- `langchain-community` — `SQLDatabase` utility for schema introspection
- `pandas` / `numpy` — result handling
- `pydantic-settings` + `python-dotenv` — configuration from environment variables
- SQLite (`chinook.db`) as the target database

## Setup

Requires Python ≥3.12 and [`uv`](https://docs.astral.sh/uv/).

1. Install dependencies:
   ```bash
   uv sync
   ```
2. Create a `.env` file in this directory with:
   ```
   OPENAI_API_KEY=sk-...
   OPENAI_LLM_MODEL=gpt-4o-mini
   ```
3. Open [`sql_agent.ipynb`](sql_agent.ipynb) and run the cells top-to-bottom.

## Usage

The notebook exposes a `generate_response(user_query: str)` function:

```python
generate_response("List all the customers from Brazil")
generate_response("What are the top 5 best-selling genres?")
```
